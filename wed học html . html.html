Kho Code Hữu Ích & Chia Sẻ

Nơi lưu trữ các đoạn code hữu ích (di chuột vào thẻ để nổi lên) và cho phép đăng nhập để thêm code mới mà không cần xóa code cũ.

1. Kho code hữu ích có sẵn

Di chuột vào từng thẻ để nổi lên
HTML + CSS

Đổi màu nền toàn trang

Dùng background-color trong thẻ <body> hoặc CSS để đổi màu nền[span_0](start_span)[span_0](end_span).

<body style="background-color: lightblue;">
  <h1>Xin chào!</h1>
</body>
CSS

Thẻ nổi lên khi di chuột

Dùng :hover và transform: translateY(-8px) để nổi thẻ khi chưa cần bấm.

.code-card:hover {
  transform: translateY(-8px);
}
HTML

Chèn ảnh chuẩn & co giãn

Dùng thẻ <img src="..." alt="..."> kèm max-width: 100%[span_1](start_span)[span_1](end_span)[span_2](start_span)[span_2](end_span).

<img src="anh-truong.jpg" alt="Trường THPT Ngọc Hà"
     style="max-width: 100%; height: auto;">
HTML

Mở link TikTok ở tab mới

Dùng target="_blank" để bấm link mở sang trang TikTok.

<a href="https://www.tiktok.com/@nduc567"
   target="_blank" rel="noopener noreferrer">
  TikTok @nduc567
</a>
